# BUG-001: frete é cobrado quando o subtotal é exatamente R$ 200,00

| Campo | Valor |
|---|---|
| ID | BUG-001 |
| Severidade | Alta |
| Prioridade | P1 |
| Ambiente | https://verzel-store.qa-test-verzel-store.workers.dev, v2.3.0, Chromium (app Claude, desktop) e `curl`, 2026-10-06 |
| Cenários relacionados | CT-08, CT-09, CT-20 (e CT-24) |
| Critérios violados | CA06 (e CA08) |
| Camadas afetadas | API (`/api/carrinho/calcular`, `/api/pedidos`) e UI (carrinho, checkout e pedido confirmado) |

## Pré-condições

Carrinho vazio, sem outras regras ativas.

## Passos para reproduzir

**Pela interface**
1. Abrir a loja e adicionar 4x "Garrafa Térmica 750ml" (R$ 50,00 cada).
2. Abrir o carrinho.

**Pela API**
```bash
curl -s -X POST https://verzel-store.qa-test-verzel-store.workers.dev/api/carrinho/calcular \
  -H 'Content-Type: application/json' \
  -d '{"itens":[{"produtoId":"P008","quantidade":4}]}'
```

## Resultado atual

- Subtotal R$ 200,00, **Frete R$ 19,90**, Total R$ 219,90.
- A UI mostra "Faltam R$ 0,00 para o frete grátis.", o que é contraditório.
- API: `"frete": 19.9`, `"freteGratis": false`, `"valorFaltanteFreteGratis": 0`, `"total": 219.9`.
- Com `BEMVINDO10`: desconto R$ 20,00, frete R$ 19,90, total R$ 199,90.
- O erro chega ao pedido confirmado (checkout com 4x Garrafa e o cupom confirmou Total R$ 199,90).
- Subtotais acima do limite (R$ 229,90) e abaixo (R$ 199,90) se comportam corretamente.

## Resultado esperado

Trecho da documentação (CA06): "O frete é grátis para compras com subtotal a partir de R$ 200,00, inclusive."
Trecho da regra de cálculo: "Frete: R$ 0,00 quando o subtotal é igual ou maior que R$ 200,00."

Subtotal R$ 200,00: Frete Grátis, `freteGratis: true` e Total R$ 200,00 (R$ 180,00 com BEMVINDO10, pelo CA08).

Hipótese de causa (a confirmar com o time): a comparação usa "maior que" em vez de "maior ou igual a".

## Impacto

O cliente paga R$ 19,90 a mais exatamente no valor limite da promoção, que é o valor mais divulgado ("a partir de R$ 200,00").
